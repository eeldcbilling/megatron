# Labs

One folder per lab (`lab01` … `lab11`). Each folder holds your code, a `notes.md` with what you found, and any small output files.

Rules:

- Use one virtual environment for the whole repo and keep `requirements.txt` here up to date.
- Do not commit large data files or API keys. Keys go in a `.env` file, which is ignored by git.
- You may use AI to help write code. You must be able to explain every line when asked.
